# aseprite-ansi-converter

Para instalar a extensão, basta clicar duas vezes nela no Windows ou macOS. Caso contrário, você pode instalá-la em 

`Edit` > `Preferences` > `Extensions` > `Add Extension`

e usar em

`File` > `Export` > `Export Ansi`
